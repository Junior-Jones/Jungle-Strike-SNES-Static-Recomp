Jungle Strike (SNES) Static Recompilation 1.0.0
Third-party notices

SDL 3.4.10
----------

The Windows launcher statically links SDL 3.4.10 for gamepad support. SDL's
zlib license is distributed as SDL-LICENSE.txt beside Launcher.exe and in the
source package.

Snes9x/byuu S-SMP semantic provenance
--------------------------------------

The ahead-of-time Jungle Strike S-SMP implementation was generated from a
finite semantic library derived from Snes9x/byuu S-SMP sources. The complete
256-opcode semantic library is an offline development input and is not linked
as an interpreter. Production contains only Jungle Strike's discovered exact
PC/opcode forms and rejects unknown PCs, opcode mismatches and writes to owned
audio code.

The Snes9x license and copyright notice are distributed as
SNES9X-LICENSE.txt. Its non-commercial terms apply to the derived S-SMP
semantic code. See the source package's
third_party/snes9x_smp_semantics/JUNGLE-STRIKE-USAGE.md for provenance.

Controller mappings
-------------------

The current launcher uses SDL3's built-in controller mappings. It does not
load or distribute the former gamecontrollerdb.txt development file.

Original game
-------------

Jungle Strike, its ROM and original assets are not distributed by this
project. Users must supply the exact legally obtained ROM described in
Rom\Readme.txt.
