Jungle Strike (SNES) Static Recompilation
Version: 1.2.1
Platform: Native 64-bit Windows 10 and Windows 11
Executable: Launcher.exe
ROM: Required externally; not included

New in version 1.2.1 - Window drawing and launcher support
--------------------------------------
Draws each completed frame off screen before presenting it, removing the
intermediate black clear during redraw. Controls and gameplay timing are
unchanged in both normal and widescreen modes.

Adds RecompLauncher setup, existing settings, save-backup locations and direct
ROM launching with --game. Combined display options are accepted. Personal
settings, game files and test evidence are not included in the release.

Keyboard and gamepad input were tested headlessly across missions 1-9:
all 12 keyboard actions and 12 default SDL virtual-gamepad actions passed.
All 20 mappable controller controls, disconnect/reconnect and analog dead zones
were checked. Physical USB/Bluetooth hardware was not detected during testing.

Previous version 1.2.0 - Experimental 60 FPS
----------------------------------------
Optional 60 FPS improves previously slower gameplay checks, controls, menus
and colour effects in both normal 4:3 and 16:9 Widescreen. Original movement
speed, fuel use, weapon intervals and audio timing are preserved.
Choose it before loading the ROM using the shared toolbar/menu setting.

General fixes improve busy-combat frame delivery, alternate vehicles,
damage/report return paths, information panels and widescreen save/load.
Earlier snapshots remain readable. F8 now saves a matching diagnostic report
with each screenshot to help investigate gameplay and display issues.

Previous version 1.1.0 - Widescreen
---------------------------------
Added optional 16:9 scenery on all four sides, bottom-edge gameplay messages
and a wider Map/Mission/Status panel with the original text and numbers.
The shared toolbar/menu setting and one-time Notice are remembered.
